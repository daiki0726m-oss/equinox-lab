# 買い目の仕様 (投資層)

> 正本: `strategy/betting.py` (`should_bet_race` / `trio_focus_band` / `_honor_bets` / `generate_bets`)
> と `predict.py` の sb=0 ゼロ化。点数と金額は `scripts/test_bet_structures.py` が機械的に固定している。
> **点数・条件を変えたら、このファイル・テスト・コードのコメントを同時に直すこと** (#149/#169 の
> 「同じ値が2箇所にある」再発防止)。
>
> 作成: 2026-11-05 (#169)。実測値は 9/05〜11/01 (21開催日・552R) の `predictions_cache.all_bets_json`
> (予測時に作られた買い目。`refresh_odds` に上書きされない列) と確定払戻から計算した。

## 0. 位置づけ

- 印 (◎○▲△△☆注) は**コンテンツ層**、買い目は**投資層** (#111 の役割分担)。ユーザーが自分で買い目を組む
  参考としては印と分析が主で、システムの買い目 ROI は優先度が低い (#142)。
- 控除率の壁は越えられない (#73/#75/#100/#109/#132/#139/#141)。買い方の工夫で動くのは負け幅と分散だけ。
- ここに書く「ROI」はいずれも検出力の下限 (#141: +5pt の差を見るのに約9,000R) に届いていない。
  **数字は「現状こう動いている」の記録であり、良し悪しの判定ではない。**

## 1. 全体の流れ (レース1つ)

1. `predict.py` が信頼度 (S/A/B/C/D) を決める。
2. `should_bet_race()` が投資するか (should_bet) と理由 (bet_reason) を決める (§2)。
3. `generate_bets()` が買い目を作る (§3〜§5)。信頼度 C/D は**買い目自体を作らない** (空)。
4. `predict.py` の sb=0 ゼロ化 (#95): should_bet=0 のレースは全ラインの金額を0にする。
   **例外: band (§3) は主力買い目 (honor) の三連複とワイドだけ金額を残す。**
5. `predictions_cache` に all_bets_json / should_bet / bet_reason を書き、`export_predictions.py` が
   ダッシュボード用 JSON (`all_bets` / `should_bet` / `bet_reason`) に出す。

## 3. trio-focus band (#95) と、見送り判定との優先順位

**条件** (`trio_focus_band`): 信頼度 S/A/B かつ 平場 (未勝利・新馬・障害でない) かつ ◎に実オッズ かつ
◎ 2.0〜2.9倍。

**中身**: 主力買い目の三連複を **2倍額** (1点200円)、馬連の主力買い目は作らない、ワイドは維持。

**優先順位 (#169 で明文化。挙動は変えていない)**: band は should_bet=0 でも三連複/ワイドに金額を残す
**例外経路**なので、§2 の見送り判定のうち band の条件と重なり得るもの — 4・5 (混戦)、9 (#30)、10 (EV) —
より **band が優先**する。1〜3・7・8 は band の条件側で除外されるので重ならない。

- 9/05〜11/01 に band が見送りを上書きして投資したレース:
  - #30 (1勝戦×◎2.5〜2.9倍): **13R・30,000円 → 回収 20,070円**
  - 最大EV<0.9: 1R・2,400円 → 0円
  - 4・5 (混戦) との重なり: 0R
- したがって **#30 は実効的に「1勝戦×◎3.0〜3.9倍の見送り」** として働いている。
- #30 の根拠 (1勝×A の 2.5〜3.9倍 ROI 11.5%, n=26) は #141 以前の壊れた分割の時代の値、
  band の根拠 (trio ROI 200%, n=100) も #112 の OOS では 89%、週次監視では 92R 60.3% で
  「要降格レビュー」が8週連続 (#169 の反省、T班)。**どちらも優位を主張できる検出力が無い**ので、
  優先順位は現状 (band 優先) のまま固定し、変えるならユーザーの製品判断として決める。
- #30 の1勝戦判定は `"1勝" in race_name` の名前判定で、「オキザリス賞」等の **1勝クラス特別戦を拾わない**
  (2025年以降 grade=１勝クラス 1,691R 中 234R = 13.8%)。9/05〜11/01 に ◎2.5〜3.9倍の1勝クラス特別戦は
  4R (5,800円 → 13,950円、うち1Rは band)。`races.grade` に寄せるかは #30 の再検証とセットで決める (未着手)。

**理由文と表示 (#169)**: band が上書きしたレースの bet_reason は
「trio-focus band で三連複/ワイドのみ投資 (通常の判定なら見送り: 〈上書きした理由〉)」
(`BettingStrategy.band_override_reason`)。旧文面は「〈見送り理由〉 (trio-focus band: 三連複/ワイドのみ投資)」で、
見送りの理由を読ませながら 2,400円が入っていた。ダッシュボード (`docs/index.html` / `docs/predict.html`) は
should_bet=0 のレースの買い目欄の先頭に、金額がある時「🎯 三連複/ワイドのみ投資 (trio-focus band)」、
無い時「⏭️ 投資見送り — 買い目は参考表示」と理由を1行で出す。should_bet は 0 のまま (投稿選定や週次監視が
使っているので変えない)。

### 構造A の相手は印ではない (#121)

構造A の三連複の相手は**印ではなく LGB の複勝 (pred_top3) 上位4頭** (◎を除く)。#121 は
「○ (当時の妙味枠) が弱い」ことを理由にモデル順へ戻したが、その前提は #140 (○=実力2位・妙味は☆) と
#147 (○▲△△=点数表2〜5位) で崩れている。9/05〜11/01 の平場の A 形 101R 中 75R (74%) で無印馬が相手に入る
(資金ありでは 59R 中 44R)。資金の入った A 54R (9/12〜11/01) では現行 91.3% vs 印○▲△△ 58.0%、
差の95%CI [−91, +26]pt で区別できない → **現行維持、統一するかは製品判断**。
band の10頭以下も構造A の分岐が先に当たり、同じく LGB 上位4頭 (6点×2倍) になる (11頭以上の band は印相手 10点)。

## 5. 予算 (#169)

- 1レースの基本予算 1,000円 (`MAX_BET_PER_RACE`)、1点 100円 (`MIN_BET`。#140 以降は信頼度によらず一律。
  `CONFIDENCE_SIZING=1` で旧倍率 S=200円/A=100円)。band の三連複は単価2倍。
- **構造 (A/D/G) か band が決まったレースは、設計どおりの全点を買う**: `_honor_bets` は全点を計画してから
  「計画した点の合計」まで予算を広げて買う。
  - #169 以前は構造ごとの固定式 (band amt×25 / D amt×29 / A・G amt×11) で、これは**ワイド5点前提**だった。
    #146/#149 でワイドを6点にした後、各構造の最後の1点 (A: プール3位×4位、band: △×△、D: 最後の三連単) が
    予算切れで黙って落ち、**A 6→5点、band 10→9点、D 24→23点**になっていた
    (9/05〜11/01 の資金の入ったレースで A 59R 中 57R、band(11頭以上) 41R 中 40R が1点欠け)。
- 構造が決まらない時 (実オッズ無し) は従来どおり 1,000円が上限で、計画順 (馬連→ワイド→三連複) に入る分だけ買う。
- **EV層** (主力買い目の後に足す 単勝/複勝/ワイド/馬連/三連複/三連単。`MIN_EV 0.8 ≤ EV < MAX_EV 2.0`、
  ハーフケリー、無ければ券種別フォールバック) は「予算 − 主力買い目」の残りの範囲で作る。
  - A・G・D・band(11頭以上) は主力買い目が予算を使い切るので EV層は0。
  - band(10頭以下) は外側の予算が 2,500円 (`line_amount*25`) のまま残っているので、最大700円が EV層に回る
    (#95 の「band 中は馬連を作らない」は主力買い目の話で、EV層の馬連は出得る)。設計されたものではないが
    現状維持 (9/05〜11/01 で 11R・3,900円)。統一するかは製品判断。
  - #169 以前は band(11頭以上) で10点目の 200円が入らず、余った 100円が EV層に回っていた (2,500円)。

## 6. D と G には資金が乗る経路が無い

- **G** (#152): G の発火条件 (◎実オッズ<2.0) は §2 の 7 (◎<2.0倍は見送り) の真部分集合で、band も ◎2.0倍以上が
  条件なので救われない → 常に sb=0 で全ライン0円。9/05〜11/01: G 61R、資金0R。
- **D** (#169): D の条件 (◎2.0〜2.9倍×11頭以上) で should_bet=1 になり得るのは信頼度 S/A/B かつ平場のレースだけ。
  それは必ず band の条件も満たすので、#150d の規則で band に差し替わる。残る D は信頼度 C/D (買い目自体が空) か
  未勝利・新馬・障害 (sb=0 で全ライン0円、band も不成立) だけ。9/05〜11/01: D 43R、三連単に資金が乗ったのは0R。
- したがって **`BET_D_NO_CHU` (#139、2026-09-01 に本番 ON) は ON にしてから一度も金額を動かしていない**。
  効果測定は成立しない。D/G が変えるのはダッシュボードに出る参考買い目の形だけ。
- #112/#113 が記録した「G ROI 143%」「D 94.2%」はどちらも一度も張られていない買い目の成績で、
  #141 以前の壊れた分割の値でもある。投資判断の根拠に使わない。
