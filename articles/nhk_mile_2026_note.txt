■ 序：「東京マイル」というコースを再定義する

NHKマイルカップは"3歳マイル王"を決める一戦だが、コースの本質は別物だ。
東京芝1600mはJRAのなかでも屈指の「上がり性能依存コース」。直線525.9m・残り3F平均34.5秒というコース特性は、3歳の段階で末脚を見せきれる馬しか上位に来られない。

EQUINOX Labが東京芝1600mの全レース(過去約7年分)をDB分析したところ、勝敗を決めている要素は人気でも血統でもなく、「特定の物理的指標」に集約されることが分かった。今回はそれを3つに絞って提示する。

■ 死角①｜上がり33秒台で「勝率17%・複勝率45%」

東京マイルの最大ファクターは"上がり3F"だ。

【上がり3F × 着順 (東京芝1600m全データ)】

⚡ 33秒台 → 勝率 17.0%・複勝率 45.0%（171頭）
　 34秒台 → 勝率  9.5%・複勝率 26.6%（379頭）
　 35秒台 → 勝率  2.7%・複勝率 12.5%（336頭）
　 36秒台 → 勝率  1.3%・複勝率  7.7%（155頭）
　 37秒以上 → 勝率  2.8%・複勝率  9.1%（143頭）

💡 AIの視点
33秒台と35秒台で**複勝率が3.6倍違う**。これはレース展開・コース距離・馬場状態の違いを統合した結果であり、「33秒台を一度でも経験している馬」がデータ上ほぼ毎回上位に絡む。NHKマイルでは過去走で33秒台を出した経験のある馬を最重視すべき。逆に、35秒台が常態の馬は3着以内に来る確率が10%台まで落ちる。

■ 死角②｜種牡馬の「コース適性」が圧倒的に効く

「3歳マイル＝大物が勝つ」という常識は、データを見ると半分しか正しくない。

【東京芝1600m × 種牡馬複勝率（5頭以上）】

1位 スクリーンヒーロー → 複勝率 62.5%（8頭）
2位 ネオユニヴァース  → 複勝率 60.0%（5頭）
3位 ステイゴールド   → 複勝率 50.0%（6頭）
4位 リアルインパクト  → 複勝率 45.5%（11頭）
5位 ゴールドシップ   → 複勝率 37.5%（8頭）
6位 ディープインパクト → 複勝率 33.3%（51頭・8勝）← 母数最大
7位 ハーツクライ    → 複勝率 29.4%（17頭）
8位 エピファネイア   → 複勝率 28.6%（14頭）

💡 AIの視点
**ディープインパクト産駒は51頭中17頭が3着以内（33.3%）で8勝**。母数の大きさからの信頼度はトップで、3歳マイルでも依然として基軸であり続けている。一方、サンプルサイズは小さいがスクリーンヒーロー・ネオユニヴァースの複勝率60%超は無視できない数字。「マイル＝サンデー系」と思い込んでいる予想者には盲点になる。

注目すべきは**リアルインパクト**（11頭中5頭が3着以内・45.5%）。父自身が安田記念連覇のマイラーで、産駒もコース適性をしっかり伝えていることがDB上で確認できる。

■ 死角③｜母父「アグネスタキオン」が複勝率37.5%

サイアー(父)の見られやすさに対し、ブルードメアサイアー(母父)は予想者の盲点になりやすい。

【東京芝1600m × 母父複勝率（5頭以上）】

1位 アグネスデジタル          → 複勝率 60.0%（5頭）
2位 Distorted Humor(米)       → 複勝率 60.0%（5頭）
3位 ブライアンズタイム          → 複勝率 40.0%（10頭）
4位 シンボリクリスエス          → 複勝率 37.5%（16頭）
5位 アグネスタキオン           → 複勝率 37.5%（24頭）← 母数最大級
6位 ディープインパクト          → 複勝率 28.6%（21頭）

💡 AIの視点
**母父アグネスタキオンが24頭中9頭で3着以内（37.5%）**。サンデーサイレンス×ロイヤルスキー(米国型スピード血統)の配合がマイラー型の瞬発力を産駒に伝える典型例だ。
さらに**シンボリクリスエス（16頭・37.5%）**はパワー寄りの中距離型に思われがちだが、東京マイルの広いコースで脚を伸ばせる適性を示している。

NHKマイルカップで穴をあける馬を探すなら、母父の欄に「アグネスタキオン」「シンボリクリスエス」「ブライアンズタイム」が入っているかをチェックすると的中率が大きく変わる。

■ 補足｜騎手データ：ルメール・レーン・川田が"鉄板"

【東京芝1600m × 騎手複勝率（10騎乗以上）】

1位 D.レーン  → 複勝率 59.1%（22騎乗）
2位 C.ルメール → 複勝率 58.6%（58騎乗）← 圧倒的母数
3位 川田 将雅  → 複勝率 46.2%（13騎乗）
4位 丸山 元気  → 複勝率 42.1%（19騎乗）
5位 戸崎 圭太  → 複勝率 38.2%（34騎乗）
6位 福永 祐一  → 複勝率 37.5%（16騎乗）
7位 武 豊    → 複勝率 29.4%（17騎乗）

💡 AIの視点
**ルメールの東京マイル58騎乗で複勝率58.6%は他コースでも上位の数字**。母数の大きさを考えると、ルメール騎乗馬は人気以上に評価する価値がある。レーンも22騎乗で59.1%とトップだが、サンプル数が少ないため信頼度はルメールに次ぐ。

逆に、過去馬券圏内率が低い騎手で人気を背負っている馬は、馬券構成上の地雷になりやすい。

■ 補足｜枠順データ：「外枠有利だが人気馬は枠で消すな」

【東京芝1600m × 枠順別複勝率】

1枠 → 複勝率 19.8%（126頭）
2枠 → 16.2%（130頭）
3枠 → 20.0%（140頭）
4枠 → 18.0%（139頭）
5枠 → 19.0%（147頭）
6枠 → 25.3%（150頭）
7枠 → 19.3%（181頭）
8枠 → 28.0%（186頭）

💡 AIの視点
**8枠28.0%・6枠25.3%が突出して高い**。直線が長く、外を回しても末脚が活きるコースだが、これは"展開の影響を受けにくい"とも読める。
ただし注意点として、枠だけで人気馬を切るのは危険。1-3人気の複勝率は55.2%（東京芝1600m全体）でほぼ枠に依存しないため、内枠でも上位人気は外せない。

■ 2026 NHKマイルカップ｜AIの結論

EQUINOX Lab(LightGBM 3モデル合成: ランク学習＋勝率予測＋複勝予測)が18頭立てを分析した結果。

【AIの推し】

◎ 5番 ギリーズボール（15人気・47.0倍 / 西塚騎手）
　└ AI複合スコア1位。SI86.7はこの世代としては平均水準だが、ランク学習モデルが上位評価。15人気の評価は市場ノイズを過剰に反映している可能性。

○ 7番 ダイヤモンドノット（1人気・3.6倍 / 川田騎手）
　└ 人気馬としては妥当な評価。SI99.1はメンバートップクラス。川田騎手の東京マイル複勝率46.2%が後押し。

▲ 17番 ロデオドライブ（2人気・6.3倍 / レーン騎手）
　└ SI101.5は出走馬中2位。レーン騎手(東京マイル複勝率59.1%)とのコンビは"鉄板候補"。

△ 9番 サンダーストラック（10人気・33.1倍 / ルメール騎手）
　└ ルメール騎手の東京マイルデータが地味に効く。SI87.4とAIの評価は割れているが、複勝の的中率では魅力。

× 1番 リゾートアイランド（16人気・66.0倍 / 佐々木騎手）
　└ 人気急落だがAI複合スコアは高め。1枠は複勝率19.8%でやや不利だが、無視はできない。

注 14番 バルセシート（8人気・21.2倍 / 北村友騎手）
　└ AI鋸状的中ロジック上の穴枠。波乱演出馬。

【信頼度: C】 ◎の勝率8.0%（18頭立て・均等比1.4倍）→ 標準

■ 締め｜AIが見ている"次の一手"

NHKマイルは荒れる年と固まる年の振れ幅が大きいレース。今年は18頭・人気分散型のため「混戦」と判断するのが妥当だ。

人気馬2頭(ダイヤモンドノット・ロデオドライブ)を軸に置きつつ、SIスコアと騎手ファクターで上位の◎ギリーズボールに少額張る。これがリスク・期待値のバランスから見たAI最適解だ。
