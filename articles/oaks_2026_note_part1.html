本レースは1938年創設、87回目を迎える歴史あるクラシック競走。桜花賞(阪神芝1600m)に続く牝馬2冠目で、秋華賞(京都芝2000m)と合わせて牝馬三冠を構成する。

東京芝2400mのコース特性:

・スタートから1コーナーまで約350m(短い)

・コース1周をフルに使い、直線は525.9m(平坦)

・全体に高低差わずか2.7m、JRA屈指のフラットコース

つまり「持久力 × 末脚 × 折り合い」を全部要求される設計。スピード偏重の馬は最後に脚が止まり、純粋な距離適性の差が露呈する。「桜花賞1着 = オークス本命」とは限らない理由がここにある。

🎯 2. 法則① — 過去のオークス勝ち馬パターン

📊 過去6年(2020年〜2025年)勝ち馬の傾向

共通点:上がり3F 33.1〜34.0秒の決め手必須

過去6年のオークス勝ち馬を時系列で並べてみる:

🏆 2020年 デアリングタクト(1人気・単勝1.6倍・上がり33.1)

🏆 2021年 ユーバーレーベン(12人気の大波乱)

🏆 2022年 スターズオンアース(2人気で堅実)

🏆 2023年 リバティアイランド(1人気・無敗3冠1冠目)

🏆 2025年 カムニャック(4人気・単勝14.3倍・上がり33.8)

ここから読み取れる本質:

📌 ① 末脚絶対値が高い馬しか勝てない

上がり3F 33.1〜34.0秒。これは東京コース新馬戦で凡走するレベルの馬には絶対に出せない時計。直線でキレる末脚を持つ馬を最優先で評価する。

📌 ② 「1番人気=本命」は半分しか正解しない

過去6年で1番人気が勝ったのは2020年デアリングタクト・2023年リバティアイランドの2回のみ(33%)。2〜4人気の差し馬から拾うのが本筋。これは桜花賞→オークスの距離延長で、適性差が露呈するため。

📌 ③ 18頭立てG1=波乱含み

2021年ユーバーレーベン(12人気)・2025年カムニャック(4人気)のような中穴〜大穴決着が周期的に発生。当社v9システムでもG1×18頭は信頼度を1段階下げる仕様(後述)。

🎯 3. 法則② — 東京芝2400m コースバイアス

🚀 上がり3F最速馬の複勝率 = 82.1%

勝率も47.0%(過去6年117走中55勝)という異常値

東京芝2400mの過去6年データ(1,178走)を解剖すると、衝撃の数字が浮かぶ:

📊 コース全体平均:勝率 約8% / 複勝率 約25%

📊 上がり3F最速馬:勝率 47.0% / 複勝率 82.1%

つまり「2頭に1頭が勝ち、ほぼ全頭が複勝圏」。コース平均と比較すると勝率は5.9倍、複勝率は3.3倍に跳ね上がる。

📌 3.1 枠順傾向 — 1枠が驚異の29.2%

同じく東京芝2400mの過去6年・枠別複勝率:

・1枠:複勝率 29.2%(120走中35走)← 圧倒的

・4枠・5枠:複勝率 26.5%(中位優勢)

・2枠:複勝率 20.2%(120走中25走)← 凹

・8枠:複勝率 24.5%(188走中46走)

1枠が抜けて高い理由:スタートから1コーナーまで350mと短いため、内枠先行の経済コースが活きる。一方、極端な外枠でも東京2400mは長い直線で挽回可能。「2枠だけ凹む」のは過去6年のデータで明確に表れている興味深いバイアス。

📌 3.2 桜花賞→オークスの距離延長 +800m の壁

桜花賞1600m→オークス2400mは+800m。これはJRA重賞でも稀な大幅延長で、純粋なスピード型は脚が持たない。当社v9穴予兆スコアでも「+400m以上の大幅延長」を穴予兆として+3点加点する根拠の一つ(過去11,265レース統計で実証)。

📌 注目すべき構造

2026年オークスの構図は「桜花賞勝ち馬スターアニス(単独参戦)vs フローラSワンツースリー(ラフターラインズ・エンネ・リアライズルミナス)」。桜花賞2-3着馬が回避したため、桜花賞組 vs トライアル組の「世代対決」がよりシンプルに浮き彫りになる。

過去のオークスでも「桜花賞馬がオークスで2着以下に沈む」事例は2024年・2025年で2年連続発生(チェルヴィニアは桜花賞3着→オークス1着、カムニャックは桜花賞7着→オークス1着)。桜花賞→オークスの直行ではなく、トライアル経由組から拾うのが近年のセオリーになりつつある。

🤖 5. AI予想システムの設計思想 — v9 ロジック解剖

ここから、当社が運用する競馬予想AIシステム「EQUINOX Lab」の設計を初公開する。

5.1 LightGBM 3モデル アンサンブル

当社AIは3つの異なるLightGBMモデルを並走させ、最終予測を統合する設計:

🧠 ① LambdaRankモデル(順位学習)

レース内の出走馬を「順位」として学習。順位ベースの目的関数で、「どの馬が他の馬より速いか」を最適化する。

🧠 ② Win確率モデル(2値分類)

各馬が「1着になる確率」を独立に予測。Binary Logloss を最小化する。

🧠 ③ Top3確率モデル(2値分類)

各馬が「3着以内に入る確率」を予測。複勝・ワイド戦略の根幹。

これら3モデルの出力を統合する際、当社ではIsotonic Regression 後校正を適用。バリデーションセットで学習したキャリブレータが、本番分布のズレを補正する。

5.2 v9 穴予兆スコア(anasanee_score)

2026年5月、過去11,265レースを分析した結果、「人気薄(10人気以下)が3着以内に絡む条件」を統計的に特定。これをスコア化したのが v9 穴予兆スコア。

主な加点要素:

・前走10着以下からの復活 → +4点(穴馬の45%が該当・上位人気の7.5倍)

・+400m以上の大幅延長 → +3点(穴馬の発生率2.7倍)

・追込・差し脚質 → +3点(追込馬は上位人気の3.3倍)

・馬体重-10kg以上の絞り込み → +2点(1.9倍)

・穴出しサイアー(ドレフォン・ロードカナロア等) → +2点

・穴出し騎手(秋山・西村淳・藤岡佑等) → +2点

これらの合計が高い馬を、相手候補(○▲△)に優先的に拾い上げる仕組み。2026年5月17日の検証では京都1Rで▲シエーナカラー(3人気)→1着的中を実証済み。

5.3 race_volatility(レース波乱度)

同じく過去11,265レース分析から、「波乱が起きやすいレースの条件」をスコア化:

・16頭以上 → +3点(穴絡み32.5%)

・G1〜G3重賞 → +3点(35.7%)

・芝1200m → +2点(30.5%)

・福島・小倉・新潟 → +1点(25-27%)

・不良馬場 → +1点

合計4点以上で信頼度を1段階下げ、相手を厚く取る判断にシフト。

📌 2026年オークスの波乱度:18頭立て(+3) + G1(+3) = 6点。すでに「波乱含みG1」と判定される。

5.4 jockey_trust(騎手信頼度補正)

過去33,746騎乗の1-3人気時の3着内率を集計:

・信頼騎手(モレイラ68.4%・ルメール62.2%・川田60.1%等) → ◎信頼度上げ

・不信騎手(藤田菜七子39.4%等) → ◎を1段階下げ

「ルメールの本命」と「他騎手の本命」は同じではない、というデータ駆動の判断。

5.5 8軸スポットライト評価

個別馬の総合評価軸:

① 血統 × コース:過去6年の父・母父データで複勝率を算出

② 末脚絶対値:直近5走の上がり3F最速計時回数

③ 斤量適性:斤量変化と過去実績

④ 馬体重・状態:輸送減・絞り込み・気配

⑤ 同コース実績:過去走の同コースでの順位

⑥ 馬齢経年:成長曲線(3歳春時点)

⑦ 重賞経験:格上挑戦か準オープン経由か

⑧ 騎手×コース:鞍上の同コース複勝率

これら8軸スコアの合計が高い馬を「AI注目馬」として抽出する。

📚 まとめ — オークス2026を勝つための3か条

本記事で導いた本質的な3つの示唆:

① 「桜花賞勝ち馬=本命」とは限らない。近2年(2024年・2025年)は別路線組が勝利。距離延長+800mの壁を見抜き、フローラS組のラフターラインズ・エンネを相手に厚く取る。

② 東京2400mの上がり3F最速馬は複勝率82.1%・勝率47%。末脚絶対値が高い馬を最優先で評価。SI指数上位のスターアニス(92.8)・エンネ(89.6)・ドリームコア(86.1)がこのフィルタを通過。

③ 18頭立てG1は波乱含み。v9システムでもrace_volatility 6点で「相手厚め」判定。穴予兆スコアが高い馬(ジュウリョクピエロ等)を相手に拾うのが正解。さらに信頼騎手ルメール騎乗のドリームコアは jockey_trust 補正で格上げ対象。
