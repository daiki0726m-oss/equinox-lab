🗓 施行日:2026年5月17日(日)

━━━━━━━━━━━━━━━━━━

本レースは2006年創設の比較的新しい G1 だが、すでに春の古牝馬路線の頂点として確固たる地位を築いている。

東京芝1600mのコース特性:

・スタートから1コーナーまで約543m(長い助走)

・最後の直線は525.9m(平坦)

・全体に高低差わずか2.7mのフラットコース

つまり「速いペース × 純粋な末脚勝負」になりやすい設計。マイル路線の最高峰であり、誤魔化しが効かない真の力比べの舞台だ。

🎯 2. 法則① — 「上がり3F最速馬」は神話レベル

🚀 上がり3F最速馬の複勝率 = 68.1%

勝率も 34.2% という驚異の数字

東京芝1600m 過去6年データから:

📊 コース全体平均:勝率 約7% / 複勝率 約22%

📊 上がり3F最速馬:勝率 34.2% / 複勝率 68.1%

つまり「3頭に1頭が勝ち、3頭に2頭が複勝圏」。コース平均と比較すると勝率は5倍、複勝率は3倍に跳ね上がる。

この数字は他コースと比較しても異常値レベル。新潟外回りの77%には及ばないが、「東京マイルは末脚 = 全て」と言える数字。

📌 馬券戦略の核心:出走馬の直近走で「上がり3F最速」を計時した経験があるか?この一点を絶対にチェック。

🎯 3. 法則② — 「逃げ」が意外と強い、追込は壊滅

💨 逃げ馬の複勝率 36.9% / 追込馬は 10.9%

過去6年・3,002走の脚質別データ:

🔥 逃げ:勝率 12.9% / 複勝率 36.9%(217走)

○ 先行:勝率 10.7% / 複勝率 28.8%(843走)

○ 差し:勝率 7.0% / 複勝率 23.7%(910走)

⚠️ 追込:勝率 3.4% / 複勝率 10.9%(1,032走)

「東京の長い直線=差し有利」というイメージが先行しがちだが、データを見るとそれは半分嘘。逃げ・先行の馬の複勝率は合計65.7%に達する。

これはマイル戦特有のペースが原因。スタートから1Fは平均11.8秒前後で流れ、その後ペースが安定すると「前残り」になりやすい。後ろから一気の追込は届かない。

📌 戦略:逃げ馬・先行馬の中で末脚もある馬 = ベスト。後方一気の馬は減点。

🎯 4. 法則③ — 人気サイドが堅実すぎる G1

💎 1人気の複勝率 70.5% / 1-3人気の複勝率合算 60.6%

過去6年・東京芝1600mの人気別データ:

🥇 1人気:勝率 35.0% / 複勝率 70.5%

🥈 2-3人気:勝率 18.5% / 複勝率 50.6%

🏅 4-6人気:勝率 5.9% / 複勝率 27.1%

⚠️ 7-9人気:勝率 2.3% / 複勝率 10.9%

⚠️ 10人気以下:勝率 0.7% / 複勝率 3.0%

このコースはマイル王道のレースが多い(NHKマイル・安田記念・ヴィクトリアマイル等)ため、実力馬がストレートに勝ちやすい構造。

1人気の複勝率 70.5% は JRA トップクラスの「堅さ」。10人気以下の馬は勝率0.7%で、ほぼ買う意味がない。

📌 戦略:基本は1-3人気から軸を選び、4-6人気を相手に置く。7人気以下は穴狙いの保険程度に留める。

🎯 5. 法則④ — ヴィクトリアマイル特有の「波乱の年」

とはいえ、ヴィクトリアマイル G1 単独で見ると、コース全体の傾向よりも波乱がやや起きやすい。

直近の勝ち馬:

🏆 2025年:アスコリピチェーノ(1人気・2.5倍・上り33.3秒)

🏆 2024年:テンハッピーローズ(14人気・208.6倍・上り33.9秒)

🏆 2023年:ソングライン(5人気)

🏆 2022年:ソダシ(1人気)

🏆 2021年:グランアレグリア(1人気)

🏆 2020年:アーモンドアイ(1人気)

過去6年で1人気が4回的中、しかし2024年に14人気の超大波乱が起きている。これがヴィクトリアマイルの面白さ。

共通点を見ると:

・勝ち馬の上がり3F:33秒台 が多数

・1人気的中年は2.5倍以下の圧倒的人気

・波乱の年は「混戦で抜けた人気が無い」パターン

📌 戦略:絶対的1人気がいるかどうかをまず確認。2-3倍の馬がいれば素直に軸。混戦で5倍台が1人気の年は穴を絡める。

🧠 8. 5つの法則 — まとめ

法則①:上がり3F最速馬の複勝率 68% = 末脚絶対値が全て

法則②:逃げ・先行で複勝率 65% = 後方一気は届かない

法則③:1-3人気の複勝率 60% = 基本は堅実、人気サイド優先

🎯 「狙うべき馬」の理想像

✅ 1-3人気(または混戦時の中穴4-6人気)

✅ 直近で上がり3F最速を計時している

✅ 逃げ or 先行の脚質、または差しでも末脚絶対値が高い

✅ 父リアルスティール・エピファネイア・ロードカナロア系などの東京マイル適性血統

✅ 鞍上ルメール・レーン・川田のいずれか

これら5条件のうち 4つ以上満たす馬 がいれば、それが本命候補。
